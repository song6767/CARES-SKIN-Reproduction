# CARES 可穿戴多模态压力分析复现

本仓库用于记录 CARES 论文机器学习部分的独立复现：数据核验、信号预处理、传统模型基线，以及跨受试者和小样本适应实验。

## 当前状态

项目刚建立。尚未完成数据标签核验、模型训练或论文结果复现，因此这里暂不报告性能数字。

## 拟开展的实验

1. 核对模态、采样时间、实验阶段和标签，形成数据字典。
2. 复现特征提取与 XGBoost 基线，明确与论文设置的差异。
3. 使用留一受试者法评估新用户表现。
4. 比较无适应与少量目标用户标注下的适应方法。

压力/放松检测、压力源分类和焦虑评分预测是不同任务；只在相应标签可核实后开展。所有报告将注明数据划分方式，并避免训练与测试窗口或受试者之间的信息泄漏。

## 数据获取

**本仓库不包含 CARES 原始或对齐后的数据、论文 PDF，也不镜像作者的数据仓库。**请从[作者的 CARES 数据仓库](https://github.com/CARES-eskin/StressData)自行获取，并遵守原始来源的使用条件。参见 [DATA.md](DATA.md) 了解本地目录约定。

Xu et al., “A physicochemical-sensing electronic skin for stress response monitoring,” *Nature Electronics* 7, 168–179 (2024). [DOI: 10.1038/s41928-023-01116-6](https://doi.org/10.1038/s41928-023-01116-6)。
